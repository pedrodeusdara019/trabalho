# SportsHub

Site esportivo estático, responsivo e sem dependências externas.

## GitHub Pages

1. O `index.html` está na raiz deste repositório.
2. Vá em **Settings → Pages**.
3. Selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Salve para publicar.

Os placares, classificação e notícias deste protótipo são ilustrativos.
